# FV CODE — сайт агентства

Многостраничный сайт + встроенная админ-панель. Никакого сервера не нужно — всё работает на GitHub Pages, а весь контент (услуги, портфолио, отзывы, история, команда, фото сотрудников, контакты) хранится в одном файле `data.json` и редактируется прямо из браузера через `admin.html`.

## Структура файлов

```
index.html        — главная (тизеры + превью портфолио/отзывов)
about.html         — о нас
services.html       — услуги
process.html        — как мы выполняем услуги
portfolio.html      — портфолио
reviews.html        — отзывы
history.html        — история агентства
team.html           — команда
contacts.html       — контакты + форма заявки
admin.html          — админ-панель
data.json            — весь контент сайта (редактируется через админку)
assets/style.css     — стили сайта
assets/site.js       — логика сайта (меню, анимации, подгрузка data.json)
assets/admin.css     — стили админки
assets/admin.js      — логика админки (работа с GitHub API)
assets/team/         — сюда админка кладёт загруженные фото сотрудников
```

## 1. Публикация на GitHub Pages

1. Создайте репозиторий на GitHub, например `fvcode-site`. **Репозиторий должен быть публичным**, если у вас бесплатный аккаунт GitHub (иначе GitHub Pages не заработает; на платном плане подойдёт и приватный).
2. Загрузите в него все файлы из этого проекта, сохранив структуру папок (`assets/` вместе с содержимым).
3. В репозитории откройте **Settings → Pages**.
4. В разделе **Source** выберите ветку `main`, папку `/ (root)` → **Save**.
5. Через 1–2 минуты сайт будет доступен по адресу:
   `https://<ваш-логин>.github.io/<название-репозитория>/`

## 2. Настройка админ-панели (самое важное)

Админка редактирует контент, коммитя изменения прямо в `data.json` в вашем репозитории через GitHub API. Чтобы это работало, нужен **Personal Access Token** — ключ доступа к вашему GitHub-аккаунту.

### Как создать токен

1. Зайдите на **https://github.com/settings/tokens**.
2. Нажмите **Generate new token → Generate new token (classic)**.
3. Название — любое, например `fvcode-admin`.
4. Срок действия — на ваше усмотрение (можно "No expiration", но это менее безопасно).
5. Отметьте галочку **repo** (полный доступ к репозиториям) — это даёт право читать и записывать файлы.
6. Нажмите **Generate token** и **скопируйте его сразу** — второй раз GitHub его не покажет.

⚠️ Токен даёт доступ к вашим репозиториям — храните его так же, как пароль. Никому его не передавайте. В самой админке токен сохраняется только в `localStorage` вашего браузера (на вашем устройстве) и отправляется напрямую в GitHub API — на другие серверы он не попадает.

### Как подключить админку

1. Откройте `https://<ваш-логин>.github.io/<репозиторий>/admin.html`.
2. Заполните:
   - **Владелец репозитория** — ваш GitHub-логин (например `TrumpSCH`).
   - **Название репозитория** — например `fvcode-site`.
   - **Ветка** — обычно `main`.
   - **Personal Access Token** — токен, созданный выше.
3. Нажмите **«Подключиться и загрузить данные»**.
4. Появятся формы для редактирования всех разделов сайта.

### Что можно редактировать

- **Главный экран** — заголовок, подзаголовок, цифры статистики.
- **Услуги** — добавление/удаление/редактирование карточек услуг.
- **Как мы работаем** — шаги процесса.
- **Портфолио** — проекты, теги, технологии, цвет карточки.
- **Отзывы** — имя, роль, текст, оценка.
- **История** — этапы таймлайна.
- **Команда** — имя, роль, Telegram, описание, **фото** (загружается файлом и автоматически коммитится в `assets/team/`).
- **Контакты** — ссылка на Telegram-канал и текст про время ответа.
- **JSON целиком** — блок внизу для ручного редактирования всего файла разом (для сложных правок).

После изменений внизу экрана появляется панель **«Сохранить и опубликовать»** — нажмите её, чтобы закоммитить изменения в GitHub. Сайт на GitHub Pages обновится автоматически через 1–2 минуты.

## 3. Важные технические детали

- Сайт **не будет работать корректно при открытии файлов напрямую** двойным кликом (`file://`) — браузеры блокируют загрузку `data.json` по соображениям безопасности. Проверяйте сайт либо через GitHub Pages, либо через локальный сервер (например, расширение "Live Server" в VS Code, или команда `python3 -m http.server` в папке проекта).
- Форма заявки на странице «Контакты» сейчас ничего никуда не отправляет — это демонстрационная форма. Чтобы заявки реально приходили, форму нужно подключить к боту, email-сервису (например, Formspree) или другому обработчику — могу сделать отдельно.
- Владелец и партнёр (`TrumpSCH`, `yoriwa`) уже добавлены в раздел «Команда» — их можно редактировать или дополнить остальными сотрудниками через админку.
- Если понадобится ограничить доступ к `admin.html`, чтобы его не нашли посторонние — можно переименовать файл в что-то менее очевидное или защитить паролем через GitHub Pages (например, через Cloudflare Access) — это тоже можно настроить отдельно.
