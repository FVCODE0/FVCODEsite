Здесь редактируется весь контент сайта: главный экран, услуги, процесс, портфолио, отзывы, история, команда (включая фото) и контакты. Изменения сохраняются напрямую в файл data.json в вашем GitHub-репозитории — сайт на GitHub Pages подхватит их автоматически через 1–2 минуты после сохранения.

Подключение к GitHub

Нужен Personal Access Token с правом записи в репозиторий (classic-токен со скоупом repo, или fine-grained с доступом Contents: Read and write). Токен создаётся на странице github.com/settings/tokens и хранится только в вашем браузере — никуда, кроме GitHub API, не отправляется.
